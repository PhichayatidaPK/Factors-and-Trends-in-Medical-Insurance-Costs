## 2. พจนานุกรมข้อมูล (Data Dictionary) ของ `Factors and Trends in Medical Insurance Costs.csv`

ข้อมูลหลังจากทำความสะอาดแล้วมีทั้งหมด โหลดข้อมูล 1338 แถว 7 คอลัมน์ ตารางต่อไปนี้แสดงชื่อคอลัมน์ ชนิดข้อมูล คำอธิบาย และจำนวนค่าว่างของแต่ละคอลัมน์

| คอลัมน์ | ชนิดข้อมูล | คำอธิบาย / ค่าที่เป็นไปได้ | ค่าว่าง |
| --- | --- | --- | ---: |
| `age` | ตัวเลข | อายุของผู้รับผลประโยชน์หลัก หน่วยเป็น ปี | 0 |
| `sex` | ข้อความ | เพศของผู้ทําประกันสุขภาพ ได้แก่ Male และ Female | 0 |
| `bmi` | ตัวเลข | ดัชนีมวลกายของผู้ทําประกันสุขภาพ หน่วยเป็น $กก./ม.^2$ | 0 |
| `children` | ตัวเลข | จํานวนบุตรหรือผู้ที่อยู่ในความอุปการะที่ได้รับความคุ้มครอง หน่วยเป็น คน | 0 |
| `smoker` | ข้อความ | พฤติกรรมการสูบบุหรี่ | 0 |
| `region` | ตัวเลข | พื้นที่ที่อยู่อาศัยของผู้รับผลประโยชน์ ประกอบด้วย southwest, northwest, southeast และnortheast | 0 |
| `charges` | ตัวเลข | ค่าเบี้ยประกันสุขภาพส่วนบุคคล หน่วยเป็น ดอลลาร์สหรัฐ | 0 |

**หมายเหตุ**
จากการตรวจสอบชุดข้อมูล ไม่พบค่าสูญหาย (Missing Values) ในทุกคอลัมน์ จึงไม่ต้องทำการแทนที่หรือลบข้อมูล และไม่มีการเปลี่ยนชื่อคอลัมน์ และคงเหลือจำนวนข้อมูลสมบูรณ์พร้อมนำไปใช้ทั้งหมด 1,338 แถว
