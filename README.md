## 2. พจนานุกรมข้อมูล (Data Dictionary) ของ `Medical Insurant Cost.csv`

ข้อมูลหลังจากทำความสะอาดแล้วมีทั้งหมด โหลดข้อมูล 1338 แถว 7 คอลัมน์ ตารางต่อไปนี้แสดงชื่อคอลัมน์ ชนิดข้อมูล คำอธิบาย และจำนวนค่าว่างของแต่ละคอลัมน์

| คอลัมน์ | ชนิดข้อมูล | คำอธิบาย / ค่าที่เป็นไปได้ | ค่าว่าง |
| --- | --- | --- | ---: |
| `age` | ตัวเลข | อายุของผู้รับผลประโยชน์หลัก หน่วยเป็น ปี | 0 |
| `sex` | ข้อความ | เพศของผู้ทําประกันสุขภาพ ได้แก่ Male และ Female | 0 |
| `bmi` | ตัวเลข | ดัชนีมวลกายของผู้ทําประกันสุขภาพ | 0 |
| `children` | ตัวเลข | จํานวนบุตรหรือผู้ที่อยู่ในความอุปการะที่ได้รับความคุ้มครอง หน่วยเป็น คน | 0 |
| `smoker` | ข้อความ | พฤติกรรมการสูบบุหรี่ | 0 |
| `region` | ตัวเลข | พื้นที่ที่อยู่อาศัยของผู้รับผลประโยชน์ ประกอบด้วย southwest northwest southeast northeast | 0 |
| `charges` | ตัวเลข | ค่าเบี้ยประกันสุขภาพส่วนบุคคล หน่วยเป็น ดอลลาร์ | 0 |

**หมายเหตุ**
ข้อมูลชุดนี้ผ่านการทำความสะอาดแล้ว โดยลบแถวที่มีข้อมูลซ้ำและข้อมูลสูญหายออกจำนวน 0 แถว
